# GitHub PR Reviewer Summary Bot

An AI-powered workflow that automates the initial review of GitHub Pull Requests using **n8n and Google Gemini**.

## Overview

The workflow automatically detects a new Pull Request, retrieves its details and code changes, analyzes the diff using an AI Agent powered by Gemini, and delivers the generated review summary through Gmail.

## Workflow

**GitHub PR → n8n → PR Details & Diff → Gemini AI Review → Gmail**

## Technologies

* GitHub
* n8n
* Google Gemini
* AI Agent
* Gmail

## Key Features

* Automated Pull Request detection
* Code diff retrieval
* AI-assisted code analysis
* Automated review summary
* Email notification
